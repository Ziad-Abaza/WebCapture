# استوديو التقاط المعارض والواجهات الاحترافي (Edge Studio & GitHub Frontend Extractor)

أداة محلية احترافية متكاملة مصممة لالتقاط وتوثيق واجهات المواقع وتجهيزها لمعارض الأعمال (Portfolios) على منصات العمل الحر (مستقل، خمسات، Behance، Dribbble، Upwork)، مع محرك ذكي لاستخراج وتصيير واجهات مشاريع **GitHub (Laravel / Vue / Inertia / Blade)** في بيئة معزولة دون الحاجة لتشغيل الخدمات الخلفية أو قواعد البيانات.

---

## 🚀 المميزات الرئيسية

### المرحلة الأولى: استوديو لقطات Microsoft Edge الاحترافي
- **تكامل مباشر مع Microsoft Edge**: استخدام محرك المتصفح المثبت بنظام ويندوز بأقصى سرعة واستقرار.
- **أبعاد موحدة لمنصات العمل الحر**:
  - مستقل وخمسات: `1600x1200` (4:3) أو `1200x900`
  - بيهانس ودريبل: `1600x1200` (غلاف)، `1920x1080` (16:9)، و `2880x1800` (Retina 16:10)
  - أب ورك كاتالوج: `1000x750` (4:3)
  - أبعاد مخصصة وشاشات سطح المكتب الكاملة والهواتف الحديثة.
- **مقياس دقة ريتينا (Retina Scale 2x & 3x)**: لقطات كريستالية فائقة الحدة بدون أي تشويش عند تكبير الخطوط والعناصر.
- **كشف وضبط كادر قسم الهيرو (Hero Section Auto-Framing)**:
  - كشف ذكي لأقسام الهيرو حتى لو تجاوزت حواف الشاشة (Overflow/Bleed).
  - هوامش نزيف قابلة للضبط (+/- بكسل للأعلى والأسفل واليمين واليسار) لمنع قص الظلال أو الشارات العائمة.
- **معاينة حية ومباشرة (Live Viewfinder)**: معاينة مسبقة للموقع مع إمكانية تحريك كادر اللقطة وضبط موضع التمرير (`scrollY`).
- **منع التشويه والقص**:
  - إخفاء أشرطة التمرير كلياً.
  - تجميد حركات وانتقالات CSS لمنع التمويه الحركي.
  - إخفاء إشعارات الكوكيز والنوافذ العائمة المزعجة.
  - دعم الالتقاط الكامل للصفحة (Full Page) والالتقاط الجزئي ومحددات CSS.
- **تنظيم آلي وإدارة المعرض**: حفظ منظم داخل `output/<site_domain>/` مع ملف بيانات وصفية `meta.json`، وإمكانية تصفح المعرض وحذف اللقطات وفتح المجلد بضغطة زر في مستكشف ويندوز.

---

### المرحلة الثانية: مستخرج واجهات مشاريع GitHub
- **استيراد من روابط GitHub أو مجلد محلي**: استنساخ سطحي سريع (`--depth 1`) أو فحص مسار مجلد موجود على الجهاز.
- **فحص عميق للتقنيات (Deep Stack Detection)**:
  - اكتشاف إصدار Laravel وحزم Inertia وLivewire وFilament وغيرها.
  - اكتشاف إصدار Vue ومحول Inertia Vue 3 / Vue 2.
  - اكتشاف قوالب Blade وتنسيقات Tailwind CSS وBootstrap.
  - اكتشاف أدوات البناء (Vite وLaravel Mix).
- **اكتشاف المسارات والمكونات**:
  - فحص ملفات `resources/js/Pages/**/*.vue` وربطها بالمسارات.
  - فحص قوالب `resources/views/**/*.blade.php` واستبعاد ملفات الـ Layout الفرعية.
  - قراءة `routes/web.php` ومطابقة المسارات الحقيقية للمكونات.
- **محرك المحاكاة والتصيير المعزول (Isolated Mock Engine)**:
  - **قوالب Blade**: معالجة التوجيهات (`@extends`, `@section`, `@yield`, `@vite`, `@auth`, `@foreach`)، وتوليد مصفوفات تجريبية ذكية للمستخدمين والطلبات والإحصائيات مع تغليف Layout أنيق وتطبيق Tailwind CSS.
  - **مكونات Inertia + Vue 3**: تحليل الـ `defineProps` والمكونات، وحقن بيانات افتراضية ومحاكاة بيئة Inertia وحلقات التوجيه دون الحاجة لخادم PHP أو قاعدة بيانات MySQL.
- **التقاط وتوثيق موحد**: التقاط جميع الواجهات وتخزينها بأبعاد المعارض الموحدة.
- **تقارير تدقيق شاملة**:
  - `report.json`: بيانات تقنية متكاملة.
  - `report.html`: لوحة تقرير تفاعلية فاخرة تعرض صور المعاينة والتفاصيل التقنية ونسب النجاح وأسباب أي تعذر.
  - `REPORT.md`: تقرير ماركداون جاهز للمشاركة والتوثيق.

## 💻 طريقة التشغيل

1. انقر نقراً مزدوجاً على الملف:
   ```cmd
   run.bat
   ```
2. أو من خلال الطرفية (Terminal / PowerShell):
   ```bash
   npm start
   ```
3. سيتم فتح لوحة التحكم تلقائياً على المتصفح:
   ```
   http://localhost:3000
   ```

## 📁 هيكلية المجلدات وملفات الإخراج

```text
gallary/
├── output/                              # مجلد حفظ اللقطات والتقارير
│   ├── <site_domain>/                   # لقطات المرحلة الأولى المنظمة لكل موقع
│   │   ├── capture_viewport_*.png
│   │   └── capture_viewport_*.meta.json
│   └── github_<repo_name>/              # لقطات وتقارير المرحلة الثانية
│       ├── *_preview.png                # لقطات الواجهات المستخرجة
│       ├── report.html                  # التقرير التفاعلي
│       ├── REPORT.md                    # تقرير الماركداون
│       └── report.json                  # البيانات التقنية
├── public/
│   └── index.html                       # واجهة التطبيق التفاعلية
├── src/
│   ├── edge-capture.js                  # محرك التقاط Microsoft Edge
│   ├── github-analyzer.js               # محلل مشاريع GitHub ومستخرج المسارات
│   ├── blade-engine.js                  # محرك تصيير Blade المعزول
│   ├── inertia-engine.js                # محرك تصيير وحقن Inertia Vue المعزول
│   ├── reporter.js                      # مولد تقارير HTML و Markdown
│   └── server.js                        # خادم Express المحلي
├── test_projects/                       # مشاريع تجريبية للاختبار والتأكد
├── run.bat                              # تشغيل فوري بنقرة واحدة
└── package.json
```
